## 📌 Project Overview

The **Basic Calculator** is a simple console-based application developed in **C Programming Language** as part of the **CodeAlpha Virtual Internship Program**.

This project performs fundamental arithmetic operations such as **Addition, Subtraction, Multiplication, and Division**. It utilizes **switch-case statements** to process user-selected operations and displays the calculated result efficiently.

The project is designed to strengthen understanding of core C programming concepts including variables, operators, user input/output, conditional statements, and program flow control.

## 🚀 How to Run

### Step 1: Clone Repository

```bash
git clone https://github.com/your-username/basic-calculator.git
```

### Step 2: Navigate to Project Folder

```bash
cd basic-calculator
```

### Step 3: Compile

```bash
gcc calculator.c -o calculator
```

### Step 4: Run

#### Windows

```bash
calculator.exe
```

#### Linux / Mac

```bash
./calculator
```
